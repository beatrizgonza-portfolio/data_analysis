## 🛠️ Technical Capabilities & Tools

### 1. Data Governance & Database Management (SQL)
- **Engine:** MySQL Workbench.
- **Key Skills:** Multi-system data merging, data quality auditing (detecting nulls, duplicates, and out-of-bounds outliers), conditional aggregation (`CASE WHEN`), and database normalization.

### 2. Executive Reporting & Compliance Modeling (Advanced Excel)
- **Engine:** Microsoft Excel.
- **Key Skills:** Structured tables, dynamic KPI scorecards (`COUNTIF`, `AVERAGEIF`), nested logical formulas (`IF`, `ISBLANK`), conditional formatting risk alerts, and interactive Pivot Tables with connected Slicers.

### 3. Business Intelligence & Visualization (Power BI)
- **Engine:** Power BI Desktop.
- **Key Skills:** Star schema data modeling, DAX measure creation, interactive dashboard design, and Row-Level Security (RLS) implementation.
